How Stack Works

This project demonstrates the basic Stack operations.

PUSH

Add Vehicle

A new vehicle is added to the top of the parking stack.

stack.push(vehicle)
POP

Remove Vehicle

The vehicle at the top of the stack is removed first.

stack.pop()
PEEK

View Top Vehicle

View the top vehicle without removing it from the stack.

stack.peek()
LIFO

Last In First Out

The last vehicle entering the stack is the first vehicle to leave.

LIFO Principle
JAVA IMPLEMENTATION

Stack Implementation in Java

The actual data structure is implemented using Java's built-in Stack class.

Push vehicle
Pop vehicle
Peek top vehicle
Display stack
StackParking.java 
import java.util.Stack;

public class StackParking {

    public static void main(String[] args) {

        Stack<String> parking = new Stack<>();

        // PUSH
        parking.push("MH27AB1234");
        parking.push("MH27CD5678");
        parking.push("MH27EF9012");

        System.out.println("Parking: " + parking);

        // PEEK
        System.out.println(
            "Top Vehicle: " + parking.peek()
        );

        // POP
        System.out.println(
            "Removed: " + parking.pop()
        );

        System.out.println(
            "Updated Parking: " + parking
        );
    }
}
